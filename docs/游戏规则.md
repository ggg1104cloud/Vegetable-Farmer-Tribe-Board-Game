# 《菜农部落》完整游戏规则

> 本文面向**玩家与授课教师**，把游戏里每一条规则、每一个数值都讲清楚。
> 全部数值以 `src/data.js` 与 `src/engine.js` 的**当前实现**为准（已逐条核对）。
> 开发者视角的规格见 `SPEC.md`，架构与踩坑见上级目录 `AGENTS.md`，玩法速览见 `README.md`。
>
> 最后校准：2026-10-10

---

## 0. 先认识三个词

| 词 | 含义 | 提示 |
|---|---|---|
| **部落** | 游戏里的 4 个玩家，长安 / 古蜀 / 丝绸 / 燕都 | 每个部落有 1 条专属「特长」 |
| **肥力币** | 本游戏的唯一货币 | 攒够「胜利线」就赢 |
| **土地格 / 片** | 赛道上有 19 格是土地；每块地能种若干「片」作物 | 「片」是最小种植单位 |

还有一组**位置**概念，理解它才能看懂「谁在行动」：

| 词 | 含义 |
|---|---|
| **座位 seat** | 部落固定坐在第几号位（A/B/C/D），**整局不变** |
| **行动次序 order** | 本局 4 个部落的**出手先后**，开局随机抽签决定，**整局不变** |
| **回合指针 turn** | 当前轮到 order 里的第几位 |
| **轮 round** | order 转满一圈算过了一轮 |

> 每局开局都会重新抽签决定出手顺序（可能不是 A→B→C→D）。顺序会公示在顶栏。

## 1. 游戏目标与胜负

一局**最多只有一个赢家**，有两条获胜途径：

**途径一：达成胜利线**

- **目标**：让自己的部落**率先攒够「胜利线」数量的肥力币**（默认 **260**）。
- **判定时机**：只在**每个部落自己回合的收尾阶段**判定。轮到谁、收尾时他的钱 ≥ 胜利线，他就获胜，游戏结束。
- **胜利线可改**：顶栏「设置」→「对局设置」→「胜利线」输入框（50 ~ 100000），默认 260。

**途径二：最后幸存者（其他部落全部破产）**

- 游戏**允许部落欠款**：钱包可以为负，但下限是 **−50 肥力币**（`RULES.debtLimit`）。
- 一旦**欠款超过 50**（即钱 < −50），该部落**宣告破产、退出本局**：名下土地全部回归无主，
  不再参与换手；**其他部落继续游戏**。
- 当**只剩最后一个未破产的部落**时，它就是「最后幸存者」，赢得本局。

**共同点**：达成任一条时**不换手，直接结束**；若所有部落都破产，则本局**无人获胜**。

## 2. 两种对局模式

顶栏右侧可切换，**切换会自动重开一局**。

| 模式 | 说明 |
|---|---|
| **本地对战** | 4 个部落全部由真人轮流点击操作（同桌玩）。画面与操作面板跟着「当前行动者」走 |
| **单机模式** | 开局选一个部落当主角（真人操作），**其余 3 个由电脑控制**；电脑每步停 3 秒（可切「⚡快速」= 0.6 秒），日志逐条播报 |

- 单机模式下电脑行动时，图板正中会出现一个**透明小窗**提示「X 部落 行动中 / 当前动作」，**不加任何蒙版**，棋盘与日志全程可见。
- 无论哪种模式，**先手 = 行动顺序的第一位**（不认座位）；单机模式也**不再**强制真人先手。

## 3. 开局准备（每人一套）

每局开始时，4 个部落各自执行：

| 步骤 | 内容 |
|---|---|
| ① 初始肥力币 | 默认 **150**。若在「对局设置」里手动填了金额，则**直接用填的值、不再叠加先手补偿** |
| ② 先手补偿 | 按**行动次序**发：order 里第 1 位 +0 / 第 2 位 +25 / 第 3 位 +45 / 第 4 位 +60。所以默认起始金是 **150 / 175 / 195 / 210**，谁最后出手谁拿得多 |
| ③ 基础种子卡 | 从 10 种作物里**随机抽 3 张候选**，取其中**前 2 张**入库（各 1 张）。其余种子只能去**种子集市**买 |
| ④ 免费买地卡 | 每人 **1 张**，可免费拿下任意一块无主土地 |
| ⑤ 棋子位置 | 全部站在**起点**（赛道第 1 格，右下角） |

> ⚠ 基础种子是**各自独立随机**的，**不同部落之间可能重复**（实测经常出现两个部落抽到同一种作物）。
> 先手补偿**按行动次序发、不是按座位号** —— 这条错了会直接毁掉平衡。

## 4. 图板与赛道（32 格）

赛道共 **32 格**，从右下角「起点」开始**严格顺时针**绕一圈：

```
0–9    底边（从右向左）：起点 → 南方红壤 → 海南砖红壤 → 种子集市 → 土壤改良站 …
10–15  左边（从下向上）
16–25  顶边（从左向右）：监狱（左上角）→ … → 种子集市（右上角）
26–31  右边（从上向下）
31 → 0 闭环回起点
```

| 土壤改良站 | 4 | 第 4 / 12 / 20 / 29 格 |
| 气象站 | 3 | 第 7 / 14 / 22 格 |
| 监狱 | 1 | 第 16 格，左上角 |

## 5. 一个回合的完整流程（5 个阶段）

无论真人还是电脑，一个回合都严格按这个顺序走：

```
① 掷骰        清空「本回合已收获」标记 → 刷新追风机会 → 监狱判定 → 掷 2 颗 d6
   ↓（若在服刑 → 本回合跳过，直接进入 ⑤）
①b 追风        仅丝绸部落：追加 1 颗「追风骰」（1~3 点），点数并入本回合总步数
② 移动        一次走完全部步数；只在【最终落点】结算：经过起点 / 过路费 / 撞监狱
③ 落格结算    落在哪一格就结算那一格（土地只播报归属；站点发卡）
④ 决策操作    买地 / 种植 / 收获 / 用卡（真人点按钮；电脑自动）
⑤ 收尾        胜负判定 → 换手
```

**关键约束**：所有决策都发生在**移动落格之后**，不是回合开始。也就是说，你**先投骰走到格子上，再决定做什么**。

**换手**：轮完一个部落，指针 +1；走完一圈（回到 order 第 1 位）则轮数 +1。游戏结束时不再换手。

## 6. 骰子与「追风」

- **每回合掷 2 颗普通六面骰 d6**，点数相加 = 本回合步数（2 ~ 12 步，7 最常见）。
- **丝绸部落特长「追风千里」**：每 **2 回合**可获得 1 次追加掷骰机会——追加投 1 颗**特制骰（1~3 点）**，点数**并入本回合同一次行走**（不是分两段走）。
  - 机会在**回合开始时**刷新，冷却按回合计数。
  - 有追风机会时，界面会弹出「追风 / 不追风」的选择框；选择**不追风**就按普通步数走。

## 7. 移动 · 经过起点 · 过路费 · 监狱

### 7.1 移动

棋子从当前格出发，沿赛道顺时针一格一格走完步数，落到终点格。走格过程中会逐格播放动画。

### 7.2 经过起点：+50

**只要在经过的格子中包含了起点（第 0 格）**，就获得 **+50 肥力币**（不必正好停在起点）。

- **燕都部落特长「丝路商队」**：每次经过起点**额外 +15**，即 **65**。
- 一次移动最多经过起点一次（一回合步数最多 12 步，赛道 32 格）。

### 7.3 过路费：只在「最终落点」收

- **只有当你真正落在别人的土地上**时，才要付过路费。
- **路过**别人的土地、踩到自己/无主地、落到站点格，**一律不收费**。
- 过路费 = 该地地价 × **50%**（地价的一半），四舍五入，**付给土地主人**。
- 付钱**允许欠款**（钱包变负），但欠款下限是 **−50**：**欠款超过 50 即破产退出本局**（见第 1 节途径二）。
  恰好欠到 50 还不算破产，只有**超过**才出局。过路费也是实际对局里**唯一**会把钱包打成负数的途径。

| 土地 | 地价 | 过路费 | 土地 | 地价 | 过路费 |
|---|---|---|---|---|---|
| 荒漠土 | 40 | **20** | 山东棕壤 | 80 | **40** |
| 西北沙土 | 50 | **25** | 南方红壤 | 90 | **45** |
| 黄绵土 | 60 | **30** | 四川紫色土 | 100 | **50** |
| 海南砖红壤 | 65 | **33** | 江南水稻土 | 110 | **55** |
| 云贵黄壤 | 70 | **35** | 东北黑土 | 120 | **60** |
| 青藏草甸土 | 75 | **38** | | | |

### 7.4 监狱

- **只有正好落在监狱格（第 16 格）**才会触发：`暂停 1 回合`。
- 下一次轮到该部落时，他**不掷骰、不移动**，直接跳过去交给下一个部落。
- **路过**监狱不触发。

## 8. 土地：买入与拥有

### 8.1 怎么买

- 前提（缺一不可）：
  1. 该格是**土地格**；
  2. 该地**尚未被任何人买走**；
  3. **你正站在这块地上**（只能买脚下的地，不能隔空买）；
  4. 钱够地价，**或者**你有一张**免费买地卡**。
- 买法：
  - 花钱：扣 `地价`，该地归你；或
  - 用免费买地卡：**不花钱**，卡片 −1，该地归你。
- 一块地一旦有主，别人不能买，只能付过路费。

### 8.2 土地的价值构成

| 属性 | 作用 |
|---|---|
| **地价** | 买入花费 + 决定过路费（×50%） |
| **肥力** | 决定这块地**最多能种几片** |
| **适配作物** | 卡面标注的推荐作物（风味展示） |
| **质地 / pH / 区域 / 知识** | 科普内容，影响「实际高收益」的判定（见第 9 节） |

## 9. 种植（重点详解）

这是全游戏最核心、也最容易搞混的一环。逐条讲清。

### 9.1 一块地能种几片？—— 由「肥力」决定，是**上限**不是义务

| 肥力 | 可种片数上限 |
|---|---|
| 低 | **1 片** |
| 中 | **2 片** |
| 中高 | **3 片** |
| 高 | **3 片** |

- **只有「中高」和「高」肥力的地才能种到 3 片**；低肥力只有 1 片。
- 上限**不强制种满**：你可以只种 1 片、2 片……只要不超过上限、且剩余空位够。
- **片数可以少种**：比如 3 片上限的地，你可以只种 1 片试试水。

### 9.2 能不能「混搭」？—— **能，而且很灵活**

**能混搭。** 一片一记录，每片独立作物。具体来说：

- **同种重复**：一块地可以种 3 片**同一种**作物（比如 3 片玉米）。
- **不同混搭**：一块地可以种成「1 片水稻 + 1 片油菜 + 1 片玉米」。
- **任意组合**：只要**剩余空位**够、你**手上有对应种子**，怎么搭配都行。

**操作上的两点注意**：

1. **一次种植动作 = 一种作物 + 指定片数**。弹层里先选「片数」，再点某张作物卡 → 一次性种下该作物的 n 片。
2. 想混搭，就**在同一回合、对同一块地再种一次**（换另一种作物）——只要还有空位、且这块地本回合还没收获过。界面上种完会回到操作框，可继续点「种植」。

### 9.3 硬门槛：一片一张种子卡

- **手里没有该作物的种子卡，就完全不能种**（跟钱多钱少无关）。
- **种 n 片就要 n 张种子卡**（一片消耗一张）。
- 种子钱在**买卡时**就已付清，所以**种植环节不扣钱（成本恒为 0）**。

### 9.4 种植的 5 条前置（缺一即拒绝）

1. 这块地**属于你**；
2. **你正站在这块地上**（只能给脚下的土地种植；站在 a 地不能给远方的 b 地种）；
3. 这块地**本回合还没收获过**（每回合每块地只能种一轮，收获后要等下回合）；
4. 剩余空位够，且本次片数在 `1 ~ 剩余空位` 之间；
5. 手里有该作物种子，且**张数 ≥ 本次要种的片数**。

### 9.5 单片的收益从哪来

- 单片收益 = 该作物在**这块地**上的「高收益」或「低收益」值（见第 15 节作物表）。
  - 地属于该作物的「高收益土壤」→ 用**高收值**；否则用**低收值**。
- **种子省下的钱也算进这一片**：因为种植成本记 0，等于把这一片的种子钱也计入了利润。

### 9.6 延时气象卡只作用在**第一片**

- 若你手上有待发气象卡，本次种植会**自动发动 1 张**（一次性），把它的数值**只加在第一片**上（不是每片都加）。

### 9.7 一个完整例子

> 长安装（特长：山东棕壤 / 黄绵土 收获 +90%）有两块地，其中一块是**中高肥力的四川紫色土**（上限 3 片）。
> 
> - 他手上有 **2 张玉米种子 + 1 张油菜种子**。
> - 站在该地上，先点「玉米」种 **2 片**（消耗 2 张玉米种子）；再点「油菜」种 **1 片**（消耗 1 张）。
> - 这块地现在是 3 片：2 片玉米 + 1 片油菜 —— **这就是混搭**。
> - 收获时逐片结算，逐片套用「部落特长 → 改良卡增益」。

## 10. 收获（收益结算全链条）

- **前提**：这块地上**有作物**（哪怕是刚种下的）。
- **不要求站在该格**：自家囤在地里的粮，可以在任何地方收（种植才要求站在脚下）。
- **结算公式（逐片计算）**：

```
单片最终收益 = Math.round( 单片基础收益 × (1 + 部落特长加成) × (1 + 改良卡增益) )
```

其中：
- **部落特长**：土地类（长安）看土壤、作物类（古蜀）看作物；
- **改良卡增益**：每张按其**面值折算**（面值 20 = +6%，面值 5 = +1.5%），求和封顶 +48%；
- **四舍五入**：每一步都取整，避免出现 `250.26000000000002` 这样的钱数；
- **气象卡**的数值在**种植时**就已经加进那一片的记录里了，收获时不再重复。

- **收获后**：该地**作物清空**（地仍归你），并**标记「本回合这块地已收获」** → 本回合**不能再在它上面种**（防刷钱），下回合自动解除。
- **同一回合内**：可以先种再收（立即变现），但收过之后这块地本回合就不能再种了。

### 收益示例

> 长安在**黄绵土**（适配玉米：高收 65）上种 **3 片玉米**，手里有 **2 张改良卡**（地膜 5 + 滴灌 10 = 面值合计 15 → +4.5%）：
> 
> - 单片基础 = 65（高收）
> - 长安特长（黄绵土 +90%）→ `round(65 × 1.9) = 124`
> - 改良卡 +4.5% → `round(124 × 1.045) = 130`
> - 3 片合计 = **390 肥力币**

## 11. 种子与种子集市

### 11.1 种子从哪来

1. **开局基础种子卡**：每部落随机 2 张（见第 3 节）；
2. **种子集市**：落到集市格（第 3 / 9 / 17 / 25 格）可**买作物卡**。

### 11.2 买卡规则

- 集市摆出**全部 10 种作物卡**（洗牌后顺序每局不同）。
- **单一作物最多囤 3 张**；**每个部落最多同时带 6 张种子卡**（集市购买的总量上限）。
- 价格 = 该作物的**种子成本**（见第 15 节）；
  - **古蜀部落特长**：**水稻种子成本减半**（35 → 18）。
- **卡面价 / 实际扣款 / 右侧日志**三处**完全一致**（含部落折扣后价）。
- 买到的卡存在你的「作物卡手牌」里，种植时消耗。

### 11.3 种子集市还是「补货点」

- 一个部落**一张种子都没有**时，电脑会专门到集市买一张最便宜的 —— 因为「没种子什么都种不了」。

## 12. 改良卡（土壤改良站）

- **获取**：落到**土壤改良站**（第 4 / 12 / 20 / 29 格）自动抽 1 张进手牌（牌堆抽空会重洗）。
- **抽到即到账**：抽到该卡的瞬间**一次性获得它的「面值」肥力币**（面值 5 ~ 20）。
- **效果｜持有即增益（按面值折算）**：手牌里每张改良卡让收获收益增加
  **（该卡面值 ÷ 最高面值 20）× 6%** —— 面值 20 的卡给 **+6%**、面值 5 的卡给 **+1.5%**，
  所有卡**求和后封顶 +48%**。
  - **不种作物就没有增益**——增益只在收获时结算。
- **点击卡牌 = 纯弃牌**：点击某张改良卡把它弃掉，**放弃它的那份增益**（不再换钱）。
  - 电脑会在手牌超过 8 张时自动弃掉多余的卡。

## 13. 气象卡（气象站）

- **获取**：落到**气象站**（第 7 / 14 / 22 格）抽 1 张，**不立即结算**，存进「延时卡槽」。
- **发动时机**：**你下一次种植时自动发动**，一次性，用掉即消失。
- **只作用在第一片**（见 9.6）。
- **与作物无关**：气象卡的奖惩对**所有作物一视同仁**（不论水稻、小麦，都加同一个数值）——

- **可以囤多张**：这一回合不种植，卡就一直留着；多张按「先进先出」顺序发动。

## 18. 常见问题 FAQ

**Q1：一块地能种几个作物？可以混搭吗？**
A：由**肥力**决定上限：低 1 片 / 中 2 片 / 中高 3 片 / 高 3 片。
**能混搭**——3 片可以全是同一种，也可以「1 玉米 + 1 油菜 + 1 水稻」任意组合。
每片要 1 张对应种子卡，每片独立记账。

**Q2：为什么我不能给远处的自家地种植？**
A：规则要求**只能站在那块地上种**（和买地一样）。收获不受此限，可以远收。

**Q3：为什么我有钱也种不了某作物？**
A：**种子是硬门槛**。手里没有该作物的种子卡就完全不能种，一片要一张。去种子集市买。

**Q4：种植要花钱吗？**
A：**不花**。种子钱在买卡时已付清，种植环节成本恒为 0。

**Q5：为什么路过别人的地也要交钱？**
A：**不用交**。过路费**只在最终落点**收。路过、踩自己地、踩无主地都不收费。

**Q6：一块地这回合收过了还能再种吗？**
A：不能。每回合每块地只能种一轮（收获后本回合封锁，下回合自动解除）。

**Q7：气象卡什么时候生效？**
A：落到气象站是**拿卡不结算**；下一次**种植**时自动发动 1 张，只加在**第一片**。

**Q8：改良卡怎么用？**
A：**抽到即得面值肥力币**；**持有期间每张按面值折算增加收获**（面值 20 → +6%，合计封顶 +48%）；**点击卡牌 = 纯弃牌**（不再换钱）。

**Q9：怎么赢？**
A：两条路：① 在自己的回合收尾时，肥力币 ≥ 胜利线（默认 260）即获胜；② 其他部落全部欠款超过 50 破产后，自己是最后的幸存者即获胜。全员破产则无人获胜。

**Q10：谁先手？**
A：**行动顺序第一位**先手，顺序每局随机抽签，公示在顶栏。

**Q11：欠款超过 50 会怎样？**
A：该部落**破产、退出本局**（名下土地回归无主，不再换手），其他部落继续玩，直到只剩最后一个幸存者。

## 19. 课程用的 4 个科学性 BUG（**故意保留**）

这版游戏忠实还原原始设定，供学生试玩找茬、科学探究后修改规则并验证效果。
（游戏内「规则」弹层里也写明了这 4 条。）

1. **土壤数据缺失** —— 肥力只用低/中/中高/高的数字分档，没有颜色、pH、质地等实测数据支撑。
2. **改良成本一刀切** —— 劣质盐碱土和东北黑土，改良卡价格完全一样，违背「因地制宜」。
3. **生物改良无长效** —— 堆肥（生物改良）与化学改良都被做成「一次性收益」，混淆了二者的本质。
4. **气象损益统一** —— 对水稻和小麦同样奖惩，忽略作物习性差异与气候适配。

> `WEATHERS[].match` 字段存的是「优化后」的建议值，供学生对比参考。
